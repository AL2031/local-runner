Share this computer

        
Let other computers use this one's GPU and memory

        

        

        
Only turn sharing on for computers on a network you trust (home or office). Anyone on the network can use a sharing computer, and the first time you turn it on Windows may ask to allow access: choose Private networks. Speed depends on the network: wired gigabit works well, Wi-Fi is slower. A sharing computer helps one main computer at a time.
